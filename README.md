# Thanos Mod (Minecraft 26.3, Fabric)

## Сборка
1. Открой https://fabricmc.net/develop , выбери Minecraft 26.3, сгенерируй шаблон мода
   (получишь актуальные версии Loom и gradle wrapper).
2. Скопируй в шаблон папку `src/` (заменив mod id при желании) и сверь `gradle.properties` / `build.gradle`.
3. `./gradlew build` -> jar в `build/libs/`.
4. Положи jar и Fabric API 0.160.5+26.3 в папку `mods`.

## Предметы
- Перчатка Бесконечности: Shift+ПКМ — выбрать камень, ПКМ — применить.
  Пространство (телепорт), Разум (свечение+слабость врагам), Реальность (защита),
  Сила (ударная волна), Время (ускорение вам, заморозка врагам),
  Душа (полное лечение), Щелчок (исчезает половина враждебных мобов в радиусе 48).
- Двулезвийный меч, шлем/нагрудник/поножи/ботинки Таноса.
- Полный сет даёт Силу II и Сопротивление I.
- Креатив: вкладка «Бой». Крафты: см. data/thanosmod/recipe.
- Текстуры — простые заглушки, нарисованные кодом; замени своими.

## Сборка через GitHub (без установки Java)
1. Создай репозиторий на github.com.
2. Загрузи ВСЁ содержимое этой папки (включая скрытую папку .github) через Add file -> Upload files.
3. Вкладка Actions -> build -> Run workflow. После зелёной галочки скачай артефакт thanosmod-jar.
4. Возьми jar без `-sources`, положи в mods вместе с Fabric API.
